# МебельДива — мастерская необычной мебели

Этот многостраничный сайт представляет собой виртуальную витрину мастерской «МебельДива», которая изготавливает необычную, сюрреалистичную мебель на заказ. 

Проект демонстрирует использование CSS-фреймворка **Bootstrap 5** для создания современного адаптивного интерфейса.

## Реализовано в проекте

- Bootstrap Navbar с мобильным «бургер-меню» (toggler).
- Mobile-first сетка `container → row → col-*` как основа для размещения контента.
- Компоненты: **Card** (карточки товаров), **Buttons** (кнопки), **Badge** (значки «Новинка», «Хит»), **Alert** (информационные сообщения), **Table** (таблица сравнения), **Form** (формы) и **Modal** (модальное окно быстрой заявки).
- Интерактивное поведение (открытие модального окна, выпадающие списки) благодаря атрибутам `data-bs-*` и Bootstrap JS Bundle.
- Адаптивное перестроение карточек: одна колонка на мобильных, две на планшетах, три на компьютерах.
- **Дополнительный компонент:** Accordion (раскрывающийся список частых вопросов) на странице товара.

## Запуск

Откройте файл `index.html` в любом современном браузере. Подключение к интернету не требуется: файлы Bootstrap CSS и JS Bundle находятся локально в папке `vendor/bootstrap/`.

Для проверки работы сайта изменяйте ширину окна браузера, открывайте мобильное меню и модальное окно «Оставить заявку».
